# Web 0.9：任意学科的课程学习空间

2026-10-29。实现状态：本地验收完成；本轮 Sites 源码服务返回 HTTP 500，尚未发布到公开站。

## 学生流程

首页 → 创建课程（名称、学科、目标均自由填写）→ 上传自己的材料 → 勾选资料范围 → 检索原文 / 与 TA 学习 → 独立复测 → 核查并更新记忆。

六个可自动检查的旧课程移到「示例练习」；旧笔记、题目和复习记录保留。新课程与旧 CoursePack 独立，不会自动迁移旧笔记或改变原评分逻辑。

## 已实现

- 每个登录账户最多 30 门自定义课程，任意学科。课程及学习数据跨会话保存。
- PDF、DOCX、TXT、Markdown、CSV：浏览器提取纯文本 → 预览修改 → 保存正文。每份最多 10MB、100 页、10 万字；每课最多 30 份，全账户正文总计 200 万字。PDF 页码随分段保留。保存提取文字，不保存原二进制文件。
- PNG/JPEG/WebP：可选视觉模型识别，每张最多 2MB；明确同意后发送 OpenAI，核对提取结果再保存。扫描 PDF 不会静默丢页，需要先 OCR 或转图片。图片识别尚未用真实模型验收。
- RAG：持久化 1,200 字片段、200 字重叠，中文字符/双字和英文词分词，BM25 排序；严格限定当前账户、当前课程、勾选资料，最多检索 5 段。无命中不伪造引用。回答保存当时引用的片段快照和页码。此版本没有 embeddings、向量索引、混合检索或 reranker。
- Memory：按课程存储学习者主动记录、TA 待验证假设、复测自评。按问题检索相关记忆，展示来源；可关闭调用、编辑或删除。模型假设不会升级成“已掌握”。记忆删除不抹去历史回答当时使用的快照，删除课程或全部数据会一起删除。
- TA：任意学科提示策略，竞争解释、区分问题、小提示及迁移题；历史学使用史料比较，数学可用反例，实验学科可用控制变量。接入可选 OpenAI Responses 结构化输出。课程最近 6 轮历史、目标、选中资料的检索片段及可选相关记忆进入上下文。
- 可使用站点配置的模型，或填写仅存在本次页面内存中的 OpenAI Key 和模型 ID。Key 随请求经过本站服务器转发，不写数据库或 localStorage；刷新后消失。没有有效模型时，课程/检索/手动记忆/复测仍工作。真实对话需有效凭据，不提供模拟回答冒充模型。
- 独立复测：保存问题后隐藏本课聊天并拒绝模型提示；首次回答通过 revision CAS 锁定；提交后由学习者填写依据与自评，明确是否使用帮助。自评写入记忆并给出 1 或 7 天复习日期；不发送通知，不代表客观评分或因果效应。
- 账户导出/删除覆盖新表；课程删除联动资料、对话、记忆、复测。历史私有数据不进入公开首页。

## 架构

`app/study.tsx` 是课程学习入口，`app/source-upload.tsx` 负责导入；`app/api/study/route.ts` 管理课程和学习生命周期，`app/api/study/extract/route.ts` 接入可选图片识别。`lib/knowledge.mjs` 提供确定性的分段、检索、记忆召回与复测状态转换；`lib/tutor.mjs` 和 `lib/vision.mjs` 隔离模型协议。D1 的 5 张 `study_*` 表通过追加迁移 `0003_awesome_tyger_tiger` 创建。

## 验证与边界

- TypeScript 检查、34 个单元测试、构建和全新隔离 D1 的集成流程通过。
- 集成测试覆盖匿名/来源检查、跨账户和跨课程访问、资料选择范围、页码检索、并发首次回答、不能覆盖答案、证据记忆、导出和删除联动。
- 浏览器实测历史学课程、PDF/Word 解析、中文检索、记忆保存、首次作答、核查和复习日期；390px 手机视口检查并修复横向溢出。
- 模型适配器使用 mock 协议验证。未配置真实模型凭据，没有真实生成质量、视觉 OCR 质量或教学收益数据。
- 支持任意学科接入，不承诺每个学科都有可靠自动判分。因果教学目前是可审查的诊断与验证流程，不是已校准的学生因果模型，也未证明教学处理效应。

## 本地运行

```sh
npm ci
npm run setup
npm run dev
```

新安装自动应用全部迁移。已有使用 `d1_migrations` 的本地数据库由 setup 增量升级；早期手工初始化数据库要先确认已存在的表，只应用缺失的 SQL，不重放旧迁移。Sites 发布时自动应用新增迁移。生产不能直接部署此目录中的开发身份模拟器。

# TA 评估协议

当前默认评估是工程检查，不是教学效果实验。案例不含真实学生数据。

1. 运行 `npm run eval`，检查八个案例的请求契约。
2. 由维护者配置环境变量，明确执行 `npm run eval -- --live --limit=2`；最多八次调用，无自动重试。未配置时在发出请求前失败。
3. 对 `outputs/evals/` 中的每个模型回复由教师独立审阅：事实正确性、是否给最小提示、检验能否区分解释、迁移是否换了情境、材料引用是否真正支持陈述。
4. 在报告的 review 字段填写 0（不合格）、1（需改进）、2（合格）及审阅备注。关键事实错误、伪造引用或直接宣称掌握是发布阻断项；平均分不能抵消这些错误。
5. 至少两位审阅者记录分歧和裁决；公开案例覆盖、失败例子、模型 ID 和日期。真实调用成功只证明接口可用。

学习效果需要另行开展事先约定指标的研究：首次独立迁移、延迟保持、提示量与完成率；记录退出、缺失结果和提示使用。不得将用户自评、合成案例或前后变化直接报告为因果教学效果。主项目已有本机策略对照工具可用于软件演练，真实研究仍需适当设计。

0.8 本次仅运行离线协议检查；未配置模型，未进行教师审阅或真实学生试验。

# CausalTA 0.6.0a1 发布候选

这是本地 alpha 候选，尚未发布到 GitHub 或 PyPI。目标是让教师和贡献者先复现教学流程；它还不是经过真实课堂验证的完整智能 TA。

## 可直接用于发布说明的正文

CausalTA 面向计算机与数学 tutorial，提供可检查的“预测 → 实验 → 解释 → 独立迁移”流程。六个原创课程模块共享引擎；教师可以复制、编辑、校验和保存课程。默认离线，无第三方运行依赖；自然语言 TA 可通过显式配置接入 OpenAI。

0.6 增加 24 个固定合成 TA 评测场景，分别记录工程约束与待教师审阅的内容质量；真实模型评测默认零请求预算，需要显式启用。界面修复提交后键盘焦点丢失和末题反馈隐藏，改进阶段定位与窄屏显示。

源码包包含评测工具、场景、文档、测试和贡献模板；wheel 包含运行服务、课程与网页。下载后按 [安装指南](INSTALL.md) 启动。包名尚未在公共注册表发布，请从实际附带的 wheel 文件安装。

已完成本机自动测试、课程校验、离线合成场景和浏览器交互检查。跨平台 CI、真实模型质量、独立教师内容审核、真实学生学习效果仍待验证。有效引用 ID 不等于内容受支持，信息增益不等于学习增益，数学依赖关系不等于经验因果关系。仅监听本机地址，不提供公网班级平台。

欢迎贡献原创课程模块、可复现失败案例与教师审阅。代码及原创示例使用 MIT License；第三方链接内容不在此授权范围内。

## 约 90 秒演示脚本（待录制）

先用独立演示数据目录启动：`python3 -m causal_ta --data-dir .data/demo --authoring`。全程使用原创模拟例题，不展示研究参与码或学生记录。

| 时间 | 操作与讲解 |
|---|---|
| 0–15 秒 | 选择“同一个函数值，能确定同一条直线吗？”；说明学生需要预测和解释，不只收取答案。 |
| 15–30 秒 | 在截距检查题选择“12”，展示反馈和接下来的针对性追问；说明它是待核查线索，不是能力确诊。 |
| 30–45 秒 | 请求一次离线 TA 追问；展示课程依据，并明确离线预设追问不理解自由文字。 |
| 45–65 秒 | 选择查询 f(0)，填写预测并实验。根据观测 b=f(0)、m=f(1)−b，解释本轮原始状态。实际数值随会话变化，不预写正确答案。 |
| 65–80 秒 | 展示迁移阶段：原先提示隐藏，独立提交新问题；不把演示中的成绩当学习效果。 |
| 80–90 秒 | 展示教师复制模板的入口，说明课程可扩展；邀请贡献课程或审阅失败案例。 |

录制不是当前已完成的产物。模型联网、真实学生试用和教学因果效应不应在演示中被包装为已验证能力。

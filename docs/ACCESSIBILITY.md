# 键盘与窄屏使用

学生页和教师工作台均提供“跳到主要内容”链接。进入页面后按 Tab 可选中它，按 Enter 跳过页头。按钮支持 Enter，单选项支持 Space 与方向键，表单使用原生输入控件。焦点以深绿色外框显示。

## 学习流程

- 开始课程后，焦点进入课程名称；学习阶段同时带有 `aria-current="step"`。
- 回答理解检查后，焦点进入上一题反馈；反馈放在新题之前，Tab 可继续进入新题选项。最后一题完成后仍显示反馈，不再展示空的答题表单。
- 完成实验后，焦点进入预测与观察结果；实验全部完成后仍可查看最后结果。
- TA 回复后，焦点进入新增回复。不会把整段历史对话重新作为 live region 播报。
- 解释正确后进入迁移题；后续作答定位到下一题或完成回顾。迁移阶段继续隐藏理解检查、TA 和先前证据。
- 请求失败时，焦点定位到错误文字。取消删除确认后返回删除按钮。本轮没有执行浏览器中的永久删除操作。

教师复制模板后直接进入课程 ID 输入；校验、保存和错误均定位到对应结果。已有报告和课程的保存约束不因焦点变化而改变。

页面使用可换行的工具栏、单列窄屏布局与表格局部横向滚动。设置减少动态效果的浏览器会禁用课程卡片的悬浮位移与过渡；提交后的定位采用即时滚动。

## 已验证范围

2026-10-24，在本机 Codex 内置浏览器中使用独立测试数据库验证：

| 场景 | 观察到的结果 |
|---|---|
| 课程开始 / 重新开始 | 修复前焦点落到 BODY；修复后落到课程名称 |
| 仿射函数四次理解检查 | 每次定位反馈；Tab 进入下一组；末题反馈保持可见 |
| 一轮离线 TA 对话 | 焦点定位到新回复 |
| 实验、原始状态解释、两次迁移、回顾 | 焦点依次定位实验结果、迁移问题、下一题和回顾标题 |
| 跳过导航 | 首个 Tab 选中跳转链接，Enter 后焦点进入 main |
| 教师复制、校验、保存、同名拒绝 | 焦点分别在 ID、校验结果、保存结果和错误信息 |
| 320×780 CSS 像素视口 | 上述学习页与教师编辑页未出现页面横向溢出 |
| 恢复到 1280 像素宽度 | 学习页未出现页面横向溢出；测试后已撤销临时视口设置 |

演练使用按钮 Enter、单选项 Space 和 Tab 检查，以及浏览器表单填充；不代表已经逐键遍历所有页面控件。截图 `preview-keyboard-mobile.png` 和 `preview-keyboard-author.png` 均为开发代理的合成演练，回顾中的 2/2 不是学生学习效果证据。

尚未验证 VoiceOver / NVDA 的实际朗读、真实手机触摸、浏览器缩放、全部课程与所有辅助技术组合。本记录不是 WCAG 合规认证。欢迎将重复操作、焦点跳失、读屏顺序与窄屏截断的问题按具体课程、步骤、浏览器和辅助技术版本报告。

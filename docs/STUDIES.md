# 教学策略对照与数据边界

0.4 提供可选的本机研究工具。它让教学策略可以被分配、复查和比较，不自动证明某种策略有效。普通学习不需要参与研究，默认关闭参与入口。

## 先运行合成演练

```bash
python3 tools/demo_study.py
```

脚本只在临时数据库中建立 `synthetic` 研究，使用预设分组和人为分数检查软件计算。结束后临时数据库自动清理，输出仅含汇总，不含参与码、会话 token 或学生文字。数值结果可复现，创建时间随运行变化。示例输出见 [合成报告](synthetic-study-report.json)。

该例中每组分配 3 个参与码；诊断组有 2 个完成、1 个未完成，固定组有 2 个完成、1 个退出。完成者均值分别为 0.75 和 0.25，但完整分配人群的均值差可能为 0 到 2/3。它说明为什么报告不能忽略缺失结果，不是学生模型、功效模拟或教学效果证据。

## 建立本机协议

以下命令仍是软件演练。`--synthetic` 标签会固定在协议、会话和报告中，不能覆盖已有协议改成真实数据。

```bash
python3 -m causal_ta.study create --id practice-demo --course linear-functions --title '策略对照演练' --purpose '验证本机流程' --contact '本机负责人' --synthetic
python3 -m causal_ta.study invite --id practice-demo --count 2
python3 -m causal_ta.server --studies
```

创建时固定课程完整快照、版本、策略版本、两组概率、主要结果、缺失处理、数据类型和应用版本。相同研究 ID 不可覆盖。两组均使用相同课程、实验推荐和评分规则，且研究会话强制使用离线 TA：

| 策略 | 理解检查 | 离线 TA |
|---|---|---|
| `diagnostic` | 优先核查尚未被后续检查澄清的假设，否则按预设顺序 | 优先给对应假设的预设提示与追问 |
| `fixed` | 始终按课程预设顺序 | 展示下一道检查或通用回顾提示 |

这比较的是“检查顺序 + 离线追问规则”的策略组合，不能单独归因给某一条提示。学生仍可选择求助、跳过理解检查或停止，分配不等于接受了全部干预。两组都能查看理解证据，属于非盲对照。

参与者在页面输入参与码，查看目的、负责人和数据说明，自愿勾选后才能分配。每个码在首次加入时使用系统随机数独立抽组，两组各 0.5；允许随机产生不均衡人数。分组与会话在同一数据库事务中写入，重复或并发加入返回原会话。数据库只保存参与码的 SHA-256，不保存原码。教师须保管原码，并确保每人只领一个：软件不会核验真实身份，多个码对应同一人仍可能发生。

研究入口不开放创建、发码和报告的网页 API；这些操作由本机维护者通过 CLI 完成。即使服务器配置了联网 TA，研究会话也拒绝远端调用。个人学习中的非研究会话不进入研究报告。

```bash
python3 -m causal_ta.study report --id practice-demo
python3 -m causal_ta.study close --id practice-demo
```

`close` 停止新分配与发码，不停止已有会话恢复。自定义数据目录放在子命令前，例如 `python3 -m causal_ta.study --data-dir /path/to/data report --id practice-demo`；服务器使用相同 `--data-dir`。

## 策略记录

每条新理解检查事件的 `selection` 保存策略及版本、当时可选题目、已作答题目、尚待核查假设、被选题目、选择理由。它根据作答前历史生成，`recorded_at` 是服务器接受作答的时间，不是页面首次展示时间。

两种选题规则均为确定性，题目选择 `probability=1`、`randomized=false`。研究会话另有策略分组概率 0.5。两种概率不可混用：这里没有微随机试验，不能用题目事件直接估计逐提示因果效应。旧会话无历史策略记录，恢复后标记 `legacy-unrecorded`，不补造过去的决策。

## 主要结果与报告

主要结果 Y 为该参与码唯一会话中，全部独立迁移题首次作答的正确比例，范围 [0,1]。只有全部完成后才视为观察到 Y；部分作答、尚未完成和退出均为缺失。形成性检查和自由文字不进入主要得分。

每组报告已分配 N、完整结果 K、未完成、退出、缺失数，以及完成者均值。未使用的邀请单列，不进入已随机分配分母。报告校验课程快照、分组、策略版本和迁移评分与固定答案的一致性；不一致则失败，不静默计算。

设完整结果总和为 S，缺失数 M=N−K。仅利用 Y∈[0,1]，该组已分配样本的均值位于：

```text
L = S / N
U = (S + M) / N
诊断组减固定组的差值范围 = [L诊断 − U固定, U诊断 − L固定]
```

这是当前已分配样本在任意缺失结果补全下的代数界限，**不是总体 ATE 的置信区间**。软件没有计算抽样不确定性、功效、聚类调整或显著性。只有两组均有分配且全部结果完整时才输出 `all_assigned_mean_difference`；否则为 null。完成者差值单列为描述性指标。

仅分析完成者可能破坏随机分配带来的可比性，因此需事先说明并报告缺失处理。方法背景见 [Groenwold 等：随机试验中的缺失结果](https://pmc.ncbi.nlm.nih.gov/articles/PMC4203602/)。逐决策点的微随机试验涉及不同的 estimand 与历史依赖，不应与本工具的整段策略分组混用，见 [Qian 等：微随机试验的设计与分析](https://pmc.ncbi.nlm.nih.gov/articles/PMC9276848/)。

## 删除与退出

“删除本次记录”会要求页面内再次确认。普通会话删除服务端学习内容并清除本浏览器当前会话 token。研究会话同时退出，参与码失效，不再允许重新分配；最小的分组、分配时间、参与码哈希与退出标记仍保留，以报告原始分母。答题、实验、课程会话快照和对话记录从会话表删除。已下载的导出、备份和其他浏览器的缓存不受影响；这不是磁盘取证意义的安全擦除。

## 真实研究仍需补齐

目前只有开发代理演练和单元测试，没有真实参与者。正式使用前需由研究负责人审查题目、知情说明、教学适用性、招募与数据处理要求，并制定独立研究协议；本工具内置说明不能替代机构要求。还需预先规划样本量、时间预算、先验测量、延迟保持、重复身份和班级聚类的处理。`--synthetic` 只能用于软件演练，真实数据要使用单独的新研究 ID。

只支持本机使用，无班级权限或公网部署能力。协议固定不等同于第三方预注册，CLI 维护者仍控制数据库和代码。改变策略实现时需要增加策略版本并建立新研究；运行中的研究应固定应用发布版本。

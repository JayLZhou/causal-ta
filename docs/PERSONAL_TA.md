# Your Personal TA — Causal Driven

用户已确认仓库为 `JayLZhou/causal-ta`，核心目标是因果驱动的个人 TA。产品首先服务学习者自己的 tutorial；教师编辑器与策略研究工具支持这一体验。

## 个人 TA 应完成的工作

学生带来正在学的课程、题目、代码或推导，说明想学会什么。TA 先检查现有证据，必要时问一个能区分不同解释的问题，然后给出最小提示、反例、实验或先修复习。学生继续尝试，最后在没有帮助的新任务上展示理解。

“个人”要求学习者能查看、修正、导出和删除自己的学习证据。长期记录应区分课程版本、形成性练习、独立表现与不确定假设，不能把错误永久贴成人的标签。个人数据默认留在本地；调用外部模型仍需明确启用。

## 因果驱动的三个层次

1. **问题中的机制**：哪些条件可能解释现象，改变某个条件会发生什么？程序或数学检查器负责可检查的判断；数学依赖不冒充经验因果关系。
2. **当前卡点的诊断**：不同误解是否会产生相似错误？用追问区分它们，把结论保留为可修正的假设，而不是从一次答错断言能力。
3. **帮助是否有效**：提示之后做对原题不能证明学会。用独立迁移、后续保持和适当的策略比较评估；教学效应不能从诊断图直接推出。

首要产品循环是“我的任务 → 卡点证据 → 一个教学动作 → 我继续尝试 → 独立检查 → 更新我的记录”。实验底座与研究统计为它服务，不应要求普通学生先理解整套科研术语。

## 当前能力与主要缺口

| 能力 | 当前状态 | 下一步验收方向 |
|---|---|---|
| 单次会话内的个性化追问 | 根据预设错误映射和已有证据选择后续题 | 独立教师核对诊断与提示是否适当 |
| 学习记录 | 本地保存、恢复、导出与删除 | 个人工作区能找回并继续不同课程的学习 |
| 持续学习记忆 | 尚未实现跨会话、跨课程的学生状态 | 证据带来源和版本；用户可修正、遗忘与删除 |
| 自带课程材料和任务 | 目前使用显式课程包 | 材料导入后可追溯引用；不能把生成题目直接当可靠评分依据 |
| 自然语言辅导 | 可选模型接口，真实模型待验证 | 对真实问题给出适量提示；失败时明确不确定或交给教师 |
| 开放代码和证明 | 当前仅内置安全检查器与有限问题 | 受控执行或可靠 rubric；无法验证时不自动判为正确 |
| 教学效果 | 有对照研究工具，仅合成演练 | 真实独立迁移与保持证据，公开失败情况和识别限制 |

这些是产品要求，不是已实现声明。现有六个模块是可运行示例；“所有计算机与数学课程”仍通过课程与检查器扩展逐步验证。

## 后续开发优先顺序

先完成个人工作区和跨会话可追溯记录，让学习者能回来继续学；再接入个人材料与任务，并验证真实模型的提示质量。新的学科示例应围绕这些真实流程增加。公开发布使用已确认仓库；博客具体观点可在用户补充后影响研究设计，但不再作为仓库归属或个人 TA 定位的待定条件。

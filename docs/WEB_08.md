# Web 0.8：把自己的题目带进学习流程

2026-10-26，`0.8.0-alpha.1`。

## 本次实现

- **通用题目**：题目、已有尝试、卡点与概念标签；关联最多三份本人材料快照。
- **可追溯检验**：两个解释、不同预测、控制条件和选择理由先锁定，再记录结果与来源。不能区分时保留证据重新检验。
- **独立新题**：新情境、首次答案与核查依据分别提交；已答内容不可覆盖。此题提示在独立作答与核查阶段关闭。
- **长期记录**：按课程和概念聚合本人核查、情境、待区分解释与复习日期；自评与课程自动判分隔离。调度规则为 1 / 3 / 7 / 14 / 30 天，不是学习效果估计。
- **模型对接**：对话关联题目、历史按题隔离、最小当前上下文；模型建议可带回设计表单，需要本人编辑和提交。模型没有评分或数据修改工具。
- **材料**：PDF 在浏览器 Worker 内提取指定页，保留页码并预览核对。原文件不上传；模型仅接收显式选择并同意发送的材料。
- **工程交付**：追加数据库迁移、CAS 并发保护、用户隔离、删除及导出；一键本地初始化，重复迁移检查；八个模型评估案例及人工审阅协议。

## 验收证据

- 29 项 Node 测试，包括原六门课程与 Python 的状态对照、通用流程阶段门控、预测不可改写、新题首次作答、延期复习和材料边界。
- 全新隔离 D1 的 API 测试覆盖：认证、来源、跨用户访问、并发冲突、材料快照、关联对话边界、独立作答时禁用提示、删除及导出。
- 本地浏览器已走通自带题目全流程并生成 7 天后复习记录。
- 新数据库初始化及重复运行迁移验证通过。
- PDF 文本页提取、页码预览与独立 Worker 浏览器验证通过。最终替换按钮调整后的再次验收及手机布局截图被预览浏览器的原生弹窗阻塞，尚未完成。
- 八个公开合成案例仅完成离线请求协议检查；没有执行真实模型调用。

## 仍未完成

生产模型凭据尚未配置，无法宣称具备已验收的在线智能辅导。通用题目没有自动代码执行或证明检查，核查由本人完成。PDF 扫描件 OCR、公式/复杂表格可靠还原尚未实现。生产账户内读写仍需账户本人登录验收。教师审阅与真实学生学习效果实验尚未开展。

## 2026-10-27：学生入口简化

首页改为无需登录的 1 分钟数学示例，包含答错反馈、按需提示和首次作答后锁定的新题。示例采用预设规则，不调用模型、不保存数据。移除首页空统计与抽象流程图，主导航保留开始学习、跟着练习、我的题目、复习计划、我的笔记。

自带题目只要求题目、已有尝试和卡点，标题与概念可选；未填写时按该题单独记录，避免合并成同一个未知概念。设计检验拆成三步，返回上一步保留输入；提交仍遵守原有预测锁定和状态校验。在线模型未配置时，不展示题目内的无效对话入口。

验证：TypeScript、29 项核心测试、生产构建、隔离 D1 API 集成测试通过。本地浏览器实测示例答错/提示/答对/新题、三项题目录入、分步返回与最终预测保存。手机宽度检查无横向溢出。在线模型仍未配置；此轮改善可理解性，不代表自由问答或教学效果已经验证。

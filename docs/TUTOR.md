# 教学追问与可选联网 TA

## 三条独立的数据路径

1. 领域诊断：有限模型精确计算实验结果，更新题目候选状态。
2. 理解检查：教师预先定义错误选项对应的误概念假设，记录首次作答，优先选择未做过的目标追问。无法特异解释的错误保持未分类，不自动推断能力。
3. 自由文字：默认只保存在本机。离线 TA 根据已有检查证据给预设追问，明确标注不理解自由文字。可选联网 TA 才根据学生文本生成回复。自由文字和模型输出不用于改分。

## 启用方式

离线：`python3 -m causal_ta.server`。即使环境已有 API key，也不会调用外部模型。

联网：先通过自己的环境变量或秘密管理工具配置 `OPENAI_API_KEY` 和 `CAUSALTA_MODEL`，再运行 `python3 -m causal_ta.server --tutor openai`。模型 ID 必须是账户可访问且支持 Responses Structured Outputs 的模型；应用不自动替换或猜测模型，也不读用户私有凭据文件。当前没有 `.env` 自动加载功能。

随后由学生在页面勾选联网选项。仅配置服务器不会自动发送消息。每个会话最多 20 轮对话，最多输入 2000 字，单次请求上限 1200 输出 tokens、网络超时 20 秒，无自动重试。产生的费用由该 API 账户承担；当前没有账户级金额预算控制。

0.4 的研究会话固定离线：即使服务器配置了 OpenAI，界面也不显示联网选择，服务器拒绝该会话的远端请求。诊断组按待核查假设追问，固定组按预设检查顺序追问，两组共享同一课程与评分依据。

## 请求与响应

固定调用 `https://api.openai.com/v1/responses`。根据官方 [Structured Outputs 文档](https://developers.openai.com/api/docs/guides/structured-outputs)，使用 `text.format` 中的 JSON Schema，要求返回 `message`、`question`、`reference_ids`。应用还验证字段、长度与引用 ID，并处理拒绝、未完成响应和网络失败。

请求使用 `store=false`，不使用远端 conversation 或 previous response ID。每次仅发送当前会话的白名单上下文：

- 课程标题、版本、模型语义、假设、展示程序及已知输入；
- 初始观测、最近 6 条实验/理解检查证据；
- 学习目标与误概念假设的证据状态；
- 课程依据及最近 4 轮对话；
- 学生本次消息。

不加入隐藏世界、候选赋值、未答检查题、任何迁移题或其答案。学生自由文字仍可能自行包含个人信息或题目内容；应用没有自动去识别功能。`store=false` 不代表对提供方全部保留政策作出保证。

## 隔离与失败处理

模型没有工具、文件读取、数据库、Shell 或评分权限。返回值仅能成为一条可追溯的提示，不能修改题目、阶段或成绩。引用 ID 必须指向当前课程快照中已存在的依据，界面以转义后的文本展示回复。

这防止模型直接操作评分状态，但不保证生成的教学内容必然正确，也不保证提示中绝无直接解法。因此新模型、新课程和提示模板均需要教学质量审查。`reference_ids` 有效仅说明引用存在，不证明每句话被引用充分支持。

独立迁移阶段在服务器端阻止 TA 和理解检查请求，并在页面隐藏历史反馈、模型资料和导出入口，完成后恢复。当前不是防作弊考试系统：学习者拥有本机源码和数据库，不能据此声称考试安全。上游拒绝、异常 JSON、无效引用或超时会回退至离线追问，并显示回退原因；不会把 API key 或上游错误正文返回浏览器。

## 理解证据不是学习效应

一个错误选项是需要追问的线索。另一道检查答对后，界面显示“后续练习通过；迁移结果另计”，不清空错误历史、不增加迁移得分。规则的误概念映射尚未由教师独立标注验证；没有校准掌握概率，也没有教学效果因果估计。

## 验证范围

当前已测试协议构造、正常结构化回复、拒绝、截断、无效引用、网络错误降级、阶段限制和评分隔离。测试使用模拟 transport，不产生外部 API 请求。尚未调用真实提供方，因此模型权限、实际返回质量、延迟和费用尚未验证。

源码现提供 24 个跨课程合成回归场景，生成可审阅的 JSON 报告；真实模型路径设置显式请求次数上限。工程检查、答案原文匹配提示和教师语义评分分别记录，见 [TA 评测指南](EVALUATION.md)。

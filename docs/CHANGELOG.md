# 版本记录

## 未发布 · TA 评测工具

为 0.5 建立本地 Git 基线。新增六门课程共 24 个固定合成场景、课程版本检查、隐藏上下文 canary、评分状态隔离、迁移限制、引用 ID 检查及教师审阅字段。远端评测默认零请求预算，显式启用后顺序执行；降级不计为模型成功。源码发行清单包含场景 JSON，CI 增加离线场景评测。尚未运行真实 API 或教师审阅，已有 0.5 发布候选包保持原样。

## 0.5.0a1 · 2026-10-24

增加标准 Python wheel / sdist 构建与三个 CLI 入口。六个内置课程移至 `causal_ta/coursepacks/`，随安装包分发；课程 JSON 内容与 SHA-256 版本不变。源码模式保留原 `.data`，安装模式默认 `~/.causal-ta`，支持 `CAUSALTA_DATA_DIR` 与优先级更高的 `--data-dir`。

课程与验证器显式使用 UTF-8，避免依赖系统区域设置。新增真实安装检查：在临时虚拟环境、源码目录之外离线安装 wheel，验证静态资源、完整学习、教师保存、研究管理与重启恢复。61 项核心测试通过，本机 Python 3.13.5 安装检查通过。

新增安装迁移与构建指南、问题和课程贡献模板、PR 模板。CI 扩展到 Linux / macOS / Windows，但尚未在远端执行；仅生成候选产物，不自动发布。GitHub 仓库与 PyPI 发布仍待完成。

## 0.4.0a1 · 2026-10-24

新增固定顺序基线与诊断追问策略，每条理解检查记录作答前的可选题目、证据、选择理由和策略版本。题目选择是确定性规则，不把其概率与研究分组概率混淆。

新增默认关闭的本机研究模式：固定协议与课程快照、参与码哈希、自愿确认、一次性随机分配、并发幂等恢复、停止新招募、退出与记录删除。研究强制离线，避免引入不同模型条件。汇总保留未完成和退出的分母，输出缺失结果界限，明确它不是置信区间。

56 项测试通过，浏览器验证合成研究加入、固定顺序行为和刷新恢复。新增临时数据库演练脚本和纯汇总合成示例。没有真实参与者、真实教学效应或公开仓库发布。

## 0.3.0a1 · 2026-10-24

新增循环边界、二分查找、导数与条件概率模块；合计六个原创模块、24 道理解检查、12 道独立迁移题。引入内置程序检查器、除法、表达式限制与小数预测容限；数学模块区分条件化、参数变换和经验因果干预。

新增本机教师工作台：复制模板、引导编辑、完整 JSON、全状态校验、保存新课程与下载。保存需要匹配校验版本，同名拒绝覆盖；自定义课程立即可学，重启持久保留。

45 项测试通过，包括独立算术、线性搜索、样本枚举校验和原子保存与恢复。浏览器验证教师课程创建及立即试学。真实 API、教师独立备课与学生学习效果仍未验证。

## 0.2.0a1 · 2026-10-24

从题目状态诊断扩展到学生理解的可复查证据：两个模块增加 8 道形成性检查、4 个误概念假设和对应追问。可选 OpenAI Responses 对话接口与评分隔离，默认离线；真实 API 及教学质量待验证。

新会话固定课程快照和 SHA-256 版本；新增只读课程检查命令。迁移阶段禁用帮助接口并隐藏先前反馈。导出增加形成性证据和对话，提醒自由文字可能包含个人信息。

33 项自动测试通过，浏览器验证跨阶段学习、追问、证据保留与重启恢复。此版本仍为本机 alpha，尚未公开发布到 GitHub。

# 因果设计与可验证边界

## 1. 当前模型到底做什么

容器示例声明结构方程：

```text
R = 服务已运行
B = 服务监听可达接口
P = 端口映射正确
Y = R × B × P
```

在隔离模拟中 `do(B=1)` 替换 B，固定 R 和 P。每次实验从同一个原始状态开始。由于方程和初始候选空间已知，系统可以精确枚举干预结果。

这不是从真实运行日志中自动发现出来的因果图。防火墙、路由、错误端口等变量被课程假设排除。将模拟结论转移到真实容器前，必须验证这些条件。

仿射函数示例使用 `f(x)=mx+b`。查询不同 x 是函数求值；替换 m 或 b 是构造新函数。这里标记 `mathematical_dependency`，不将这种运算等同于真实世界的因果识别。

## 2. 主动诊断

设 H 为与目前证据一致的有限候选状态集合，先验在 H 内均匀。动作 a 把候选按结果 o 划分为 H(a,o)。

```text
IG(a) = log2 |H| − Σ_o [ |H(a,o)| / |H| × log2 |H(a,o)| ]
```

选择最大 IG 的问题可减少题目状态的不确定性。它不保证最好的教学效果，也不是学生误概念的概率。0.2 另有规则式学生证据记录：错误选项触发待追问假设，另一道题验证该线索。当前不拟合掌握概率、不估计 ITE，也没有从答题记录学习策略。

### 可检查性质

在模型正确、候选空间包含真值、观测无噪声的假设下，过滤 `H'={h∈H: outcome(h,a)=o}` 不会移除真实状态，且 `H'⊆H`。若动作集合能区分所有候选世界，执行足够动作可唯一辨识世界。

这是有限确定性模型的性质，不是关于学生学习速度或教学优势的新定理。测试穷举六个模块所有世界验证辨识能力，并验证多故障遮蔽和干预隔离。

## 3. 教学效应与已实现的对照工具

0.4 已实现本机两组策略分配、固定课程协议、参与说明、一次分配与恢复、退出及缺失结果汇总。普通学习不分组；研究模式默认关闭。当前只用合成数据验证软件，真实教学效应尚无证据，详见 [研究工具指南](STUDIES.md)。

研究问题：在相同题目、时间预算、材料与语言模型条件下，基于诊断证据选择提示，是否提高学生无辅助解决新题的能力？

设 X 为干预前知识测验与任务上下文，A 为被随机分配的教学策略，Y 为独立迁移测验分数。首个主要 estimand 应是策略级 intention-to-treat：

```text
ATE = E[Y(A=诊断策略)] − E[Y(A=固定提示策略)]
```

“学生收到提示以后答对”不足以识别此效应：更难的问题、更弱的先验知识或更高的求助意愿均可同时影响收到提示与表现。不能直接拿提示前后正确率相减宣称因果增益。

设计目标是学生级随机分配，避免同一学生同时使用多个策略产生交叉污染。当前实现的随机单位是参与码，负责人须保证每人只领一个码；软件不核验真实身份。若按班级随机化，估计和样本量必须考虑聚类。重复题目与学生的依赖也需在分析中处理。

微随机实验可作为后续路线；在每个 eligible 决策点对两种可接受提示随机分配并记录 propensity、available actions、前史及近端结果。需要定义干预窗口、carryover 与 sequential randomization，不能简单把每一轮对话当独立样本。

## 4. 比较设计

| 组别 | 作用 |
|---|---|
| 材料检索 + 普通回答 | 衡量基础问答支持 |
| 固定 Socratic 策略 | 控制“只是增加追问”这一解释 |
| 诊断驱动策略 | 测试基于证据选动作的增量价值 |

主指标：预先指定、教师审核的新题首次无辅助得分。次指标：延迟保持、题目完成时间、求助量、成本、学生退出、答案泄漏与教师纠错负担。用同等模型、时间和材料预算控制资源差异。

先做小规模可用性试验；正式效应研究依据最小有意义效应、分数方差、聚类和预期流失规划样本量。随机分配前确定分析计划。报告置信区间和缺失数据，不事后只选择显著的课程或学生子组。

## 6. 反例驱动的设计审查

- 一个系统同时有两个必要条件失效，单个修复无效果，不代表该条件无因果作用。
- 学生会复述正确答案，但换个数字就失败，不能判为掌握。
- 数学两个概念在先修图上相邻，不意味着学会其中一个必然使另一个提高。
- LLM 可以给出很流畅但错误的诊断；领域检查器和教师反馈应能否决它。
- 零信息增益的练习仍可能有教学价值，因此长期 teaching policy 不能只优化 IG。
- 当前 UI 公开候选集合是教学支架，不适合作为高风险考试或防作弊系统。
